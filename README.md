***

## Metadata and Social Card Audit Capabilities

* **Title and Description Validation**: Dimension analysis verifying optimal character counts for titles and descriptions.
* **Open Graph Protocol Integrity**: Comprehensive checks across og:title, og:description, og:image, og:url, and og:type tags.
* **Twitter Cards Conformance**: Validation of summary and large image card specifications for social distribution.
* **Indexability Directives**: Rigorous evaluation of meta robots tags and canonical link configurations.
* **Snippet Quality Score**: Standardised 0 to 100 benchmark featuring actionable editorial recommendations.

***

## Installation and Execution

Requires Python 3.8 or higher using standard library modules exclusively.

```bash
git clone https://github.com/TAVARDT-UK/meta-tags-inspector-uk.git
cd meta-tags-inspector-uk
python meta_inspector.py example.co.uk
```

To output machine-readable JSON:

```bash
python meta_inspector.py example.co.uk -json
```
